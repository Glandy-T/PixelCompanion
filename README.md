# Windows Pixel Companion

一个面向 Windows 的桌面像素伙伴应用。目前包含第一阶段的最小 Electron 框架：一个透明、无边框、始终置顶且可拖动的 256 × 256 像素伙伴窗口。

## 本地启动

需要先安装 [Node.js](https://nodejs.org/)（建议 LTS 版本）。在项目根目录执行：

```bash
npm install
npm start
```

窗口中的灰色像素角色为公开占位资源，不代表真实角色素材。

## 资源约定

- 真实角色素材仅保存在项目目录之外，不提交到本仓库。
- 仓库内的 `assets/characters/placeholder/` 仅用于存放可公开发布的占位资源。
- 公开占位资源不应包含可识别的真实角色形象或受限素材。
